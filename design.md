# Design Plan

# 🎨 Togetherly — Brand & Logo System (v1)

## 1. Brand Personality

**Togetherly is:**

- Warm
- Gentle
- Intimate
- Playful (but not childish)
- Calm (not loud, not flashy)

**Togetherly is NOT:**

- Corporate
- Productivity-heavy
- Social-media-like
- Gamified or streak-based

If someone opens the app at night, it should feel **comforting**.

---

## 2. Logo Concept (Locked)

### Symbol Meaning

- **Two location pins** → shared experiences
- **Heart-shaped path** → emotional connection, journey
- **Rounded faces** → human, safe, personal

This is perfect for:

- Goals → locations
- Memories → places
- Map visualization later

✅ Concept is strong — we keep it.

---

## 3. Logo Variants (You NEED all 4)

### A. App Icon (Primary)

- Symbol only (no text)
- Centered
- Soft gradient background

**Used for:**

- Android app icon
- Splash screen
- Notifications

---

### B. Full Logo

- Symbol + “Togetherly” text
- Used in:
    - Landing
    - Onboarding
    - Website (future)

---

### C. Monochrome

- White logo
- Used on:
    - Dark screens
    - Images
    - Over photos/videos

---

### D. Flat Version

- No gradients
- Used for:
    - Print
    - Low-end devices
    - Fallbacks

---

## 4. Color Palette (Final)

### Primary Colors

```
Peach / Coral:   #FF8A7A
Soft Orange:     #FFB36B
Lavender:        #B79CFF

```

### Backgrounds

```
Warm White:      #FFF6F2
Soft Cream:      #FFF1EA

```

### Text

```
Primary Text:    #3D3A3A
Secondary Text:  #8A7F7A

```

🧠 Rule:

- **Never pure white**
- **Never pure black**
    
    This keeps everything soft.
    

---

## 5. Typography (Very Important)

### App Font

**Primary:** Rounded, friendly sans-serif

Good options:

- **Nunito**
- **Inter Rounded**
- **SF Rounded** (if available)

### Usage Rules

- Titles: slightly bold
- Body: regular
- No sharp fonts
- No condensed fonts

Text should feel like it’s **talking gently**, not instructing.

---

## 6. Icon Style (Inside App)

- Rounded stroke icons
- 2px stroke
- No sharp corners
- Simple shapes

Examples:

- Heart
- Map pin
- Camera
- Clock

No filled icons everywhere — mostly outlines.

---

## 7. Illustration Style

Used for:

- Empty states
- Onboarding
- No goals yet
- No memories yet

Style:

- Soft gradients
- Rounded characters
- Minimal details
- Matching avatar style

Think: **calm, not cartoon network**

---

## 8. Motion & Animation Language

### Animations Should Be:

- Slow in
- Soft out
- Slight overshoot
- No bounce spam

### Examples:

- Goal completed → gentle scale + fade
- Memory open → slight zoom-in
- Map pin tap → soft pulse

---

## 9. Haptics Language (Locked)

| Event | Feeling |
| --- | --- |
| Partner joined | Warm celebration |
| Goal added | Gentle confirmation |
| Goal completed | Emotional success |
| Memory opened | Soft pulse |

Never harsh vibration.

Never repeated buzz.

---

## 10. Avatar Style (Preview – We’ll design next)

Avatars will:

- Match logo softness
- Rounded heads
- Minimal facial features
- Warm color palette
- No hyper-realism

They should feel like they **belong inside the logo universe**.

---

## 11. Brand One-Liners (Use Anywhere)

- *“Plan it together.”*
- *“Finish it together.”*
- *“Memories made together.”*
- *“Just for the two of you.”*
